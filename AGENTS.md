# AGENTS.md — правила для агента

Короткая инструкция для любой сессии агента в этом репозитории.
Полная версия — `docs/AGENT_GUIDE.md`.

## Главное

1. **Язык.** Код и имена — английский. Комментарии, коммиты и ответы — русский.
2. **Стек.** Godot 4.7, GDScript со статической типизацией (`var x: float = …`).
   Не тащить новые аддоны и фреймворки.
3. **Каждое изменение проверять:**
   `godot --headless --path . res://scenes/main.tscn --quit-after 20`
   В логе не должно быть `ERROR`/`SCRIPT ERROR`.
4. **Коммит и пуш после каждой законченной задачи.** Сообщение — по-русски,
   первая строка короткая, дальше пункты.
5. **TODO.** Выполнил пункт — сразу ставь `[x]` в `TODO.md` в том же коммите.
6. **Не ломать чужое.** Перед правкой читать файл; большие блоки менять точечно.
7. **Не коммитить** `.godot/`, `references/*`, временные скриншоты.

## Git: только свои файлы

Это правило появилось после инцидента: `git add -A` затащил в мой коммит
работу параллельного агента (персонаж-дампир) под сообщением «враги убраны».

1. **Никогда `git add -A` и `git add .`** — только явные пути:
   `git add scripts/player.gd docs/shot.png TODO.md`
2. Перед коммитом смотреть `git status --porcelain` и **не трогать чужие**
   изменения: не стейджить, не откатывать, не перезаписывать.
3. Если в рабочей папке есть чужие правки — просто работать рядом и
   упомянуть их в ответе, а не «прибирать».
4. **Параллельные агенты:** один коммит за раз. Либо разные ветки
   (`git switch -c character`), либо явное разделение файлов.
5. Если `git push` отклонён (`rejected`) — `git pull --rebase`, затем пуш.
   Не делать `push --force`.
6. Смешанный коммит чинится отдельным коммитом; переписывание истории —
   только по прямой просьбе пользователя.

## Проверка результата

- Счётчик кадров: **F3** в игре (fps, ms, draw calls).
- Замер в лог: `TROPA_FPS=1 godot --path . res://scenes/main.tscn --disable-vsync`
- Скриншот: запустить окно, найти через `/tmp/wlist` (macOS), снять
  `screencapture -x -o -l<id> out.png`. Фильтр окна игры: `"Width": 640/800`.
- Лабы для точечной проверки: `./run.sh character|enemies`, меню → «Объекты»/«Трава».

## Флаги окружения (для отладки)

| Флаг | Что делает |
|---|---|
| `TROPA_TOD=day/morning/evening/night` | стартовое время суток |
| `TROPA_FPS=1` | писать fps в лог |
| `TROPA_RAIN=1` | сразу дождь |
| `TROPA_NO_GRASS=1` | без травы (замер) |
| `TROPA_NO_PUDDLES=1` | без луж |
| `TROPA_NO_FOGVOL=1` | без объёмного тумана |
| `TROPA_NO_SHADOWS=1` | без теней |
| `TROPA_NO_POST=1` | без постобработки |

## Бюджет производительности

- Цель: **60 fps** при 1600×900 на M4 Pro, draw calls **< 1500**.
- Дорогие вещи: объёмный туман (объёмные боксы!), SDFGI, тени, прозрачность.
- Проверять замером до и после, цифры писать в коммит и в TODO.

## Карта проекта

```
scenes/     menu (точка входа), main (мир), labs
scripts/    main.gd (сборка мира), player, enemy, hud, пауза, стриминг травы
libraries/  деревья, объекты, костёр, качество, время суток
shaders/    дерево, трава, вода, лужа, небо, земля, мох, туман, постобработка
tools/      генератор текстур, сборка .app
docs/       гайды и скриншоты
```

## Чего НЕ делать

- Не переписывать `main.gd` целиком «для чистоты».
- Не менять фототекстуры и шейдеры без визуальной проверки.
- Не добавлять звук «заглушками», если он не проверен.
- Не обещать AAA-фотореализм: цель — стилизованный AA-инди.
