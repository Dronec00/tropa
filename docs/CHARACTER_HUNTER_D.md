# Охотник D — модель Кимы

Сгенерированная 3D-модель главного героя. Исходник лежал на рабочем столе:
`Охотник_D.blend` и `Охотник_D_Godot.glb`; в проект скопирован GLB.

## Что внутри

| Параметр | Значение |
|---|---|
| Файл | `models/hunter_d.glb` (8.7 МБ) |
| Мешей | 1 |
| Треугольников | 43 576 |
| Материалов | 1 |
| Текстуры | 4K color + normal + ORM |
| Кости | 22 (root, pelvis, spine_01/02, neck, head, clavicle/upperarm/lowerarm/hand L/R, thigh/calf/foot/toe L/R) |
| Анимационные клипы | нет |
| Рост | 1.9 м |
| Ориентация в GLB | лицом в +X |

## Как встроено

- `scripts/hunter_model.gd` — обёртка: грузит GLB, поворачивает на **+90°**
  (лицо в −Z), поднимает на 0.95 м (ступни на 0), правит материал
  (metallic 0, roughness 0.6), добавляет заливку лица и огонёк в правой руке.
- `scripts/hunter_animator.gd` — процедурные позы для 22 костей: стойка,
  шаг, бег, три удара (левая рука с мечом), блок, двуручный хват.
  Клипов в GLB нет, поэтому всё считается кодом.
- `scripts/player.gd` — если `models/hunter_d.glb` существует, герой
  собирается из него; иначе остаётся процедурный дампир.
- Витрина: `./run.sh hunter` или кнопка **«Модель Кимы»** в меню;
  в витрине работают позы 1–8, свет, ракурсы, зум тачпадом.

## Ограничения первого прохода

- лицо под полями шляпы тёмное; заливка `FaceFill` 0.24 поднимает его,
  но на крупном плане тени жёсткие;
- у плаща нет отдельных костей — он деформируется вместе с телом;
- меч в левой руке, рукоять за спиной; атака — боковой замах левой рукой;
- огонёк факела висит у правой руки приблизительно, без привязки к кости;
- 4K-текстуры занимают ~28 МБ видеопамяти; для слабых GPU нужен LOD.
