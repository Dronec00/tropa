# ГГ «Дампир» — паспорт модели

Короткая версия и чеклисты — в `TODO_CHARACTERS.md`. Здесь подробно: как
устроена модель, из чего собрана, как её смотреть и что с ней делать дальше.

## 1. Замысел

Ориентир — дампир из старых аниме про охотника на вампиров: долговязый,
молчаливый, в чёрном плаще и широкой шляпе, с длинным мечом за спиной.
Не копия персонажа, а «похож по духу»: тот же силуэт и палитра, своя игра.

Три вещи, по которым героя узнают даже в темноте:

1. **шляпа** — широкая, с поднятыми полями и янтарной изнанкой;
2. **плащ** — чёрный снаружи, тёплый янтарь внутри, рваный низ;
3. **меч за спиной** — рукоять над правым плечом, ножны по диагонали.

Плюс бледное лицо под полями и единственное цветное пятно — синий амулет.

## 2. Габариты и пропорции

| Параметр | Значение |
|---|---|
| Рост вместе со шляпой | 1.96 м |
| Рост без шляпы | 1.79 м |
| Ширина плеч (с накидкой) | 0.52 м |
| Размах плаща внизу | ~0.90 м |
| Ширина полей шляпы | 0.69 м |
| Длина меча | 1.32 м (клинок 1.02 м) |
| Длина ножен | 1.10 м |
| Кисть до земли | 0.72 м |

Ориентация: лицо смотрит в **−Z**, origin между ступнями, 1 единица = 1 м.
Игрок и витрина используют одну и ту же модель, поэтому масштаб не трогаем.

## 3. Лицо

- узкий череп, вытянутая челюсть, острый подбородок;
- длинный прямой нос с горбинкой;
- высокие скулы и лёгкая впадина под ними — «голодный» дампирский вид;
- узкие глаза, тяжёлое верхнее веко, ледяная радужка с тёмным ободком;
- тонкие бледные губы, едва заметные клыки;
- острые уши, отведённые назад;
- кожа холодная, почти серая: `#c9cbd4` в свету, `#8e93a6` в тени.

Лицо собрано из отдельной сетки-черепа (15 колец от подбородка к темени)
и накладных деталей: нос, надбровье, веки, губы, уши. Глаза утоплены,
верхнее веко прикрывает треть — взгляд получается тяжёлым, не «гугли».

## 4. Волосы

- чёрные, почти без блеска, с холодным синеватым бликом;
- два полотна чёлки расходятся от пробора к вискам;
- по бокам лица — «шторки» из полотна и трубчатых прядей;
- сзади пять длинных волнистых полотен до лопаток, поверх них — трубчатые
  пряди для объёма;
- всё висит на пивотах, аниматор качает их от скорости и ветра.

## 5. Шляпа

- тулья сужается кверху, мягкая макушка, кожаная лента с золотой кромкой;
- поля широкие, с подъёмом и острыми кончиками по бокам;
- сверху чёрный войлок, снизу — янтарная подкладка;
- овальная брошь: золотая оправа, светлый камень, блик;
- шляпа — отдельный пивот: в витрине снимается клавишей **H**.

## 6. Костюм

Слои снизу вверх:

1. **комбинезон** — облегающий, почти чёрный, с рельефом груди и пресса;
2. **высокий ворот** — расстёгнут спереди, снаружи чёрный, внутри янтарный;
3. **перевязь** через грудь, пряжка, заклёпки;
4. **амулет** — синий камень в золотой оправе на цепи из 11 звеньев;
5. **пояс** с пряжкой-черепом, подсумками и кинжалом на бедре;
6. **пальто** — полотнище вокруг бёдер с разрезом спереди, передние фалды,
   короткий верхний слой;
7. **плащ** — три сегмента, чёрный снаружи и янтарный внутри, рваный низ,
   утяжелённая кромка;
8. **накидка на плечах** — два слоя ткани и рога с серебряными кольцами;
9. **наручи** — кожа с золотой кромкой, перчатки-краги;
10. **сапоги** — высокие, с ремнями, пряжками, наколенниками и шпорами.

## 8. Скелет

```
Hips
├── ThighR/L → KneeR/L → AnkleR/L
├── Torso
│   ├── Head
│   │   ├── LidR/L            (моргание)
│   │   ├── Hat
│   │   ├── HairBack0..4      (качание)
│   │   └── CurtainR/L        (качание)
│   ├── ShoulderR/L → ElbowR/L → WristR/L → GripR
│   ├── SwordMount → HiltProp + ножны
│   ├── CapeSeg1 → CapeSeg2 → CapeSeg3
│   └── Mantle / Mantle2
└── CoatSkirt / TailR/L
```

Меч живёт в корне модели, а не в руке: аниматор каждый кадр ставит его либо
в ножны, либо в кисть и плавно переносит между ними. Поэтому вынимание
и убирание выглядят как движение, а не как телепорт.

## 9. Анимации

Аниматор — `scripts/dhampir_animator.gd`, без `AnimationPlayer`.

| Состояние | Что делает |
|---|---|
| Стойка | дыхание, покачивание корпуса, моргание, микронаклон головы |
| Шаг | ноги/руки в противофазе, покачивание таза, плащ отстаёт |
| Бег | больше амплитуда, наклон корпуса, плащ и волосы сильнее |
| Удар 1 | замах справа, диагональный рубящий, шаг вперёд |
| Удар 2 | обратный рубящий слева, разворот корпуса |
| Удар 3 | замах над головой, обе руки, рубящий вниз |
| Блок | меч перед собой, корпус в стойке |
| «Меч в руке» | режим витрины: меч остаётся в кисти |

Вынимание меча занимает первые ~0.14 с удара (кисть идёт к плечу),
убирание — последние ~0.2 с. Удар 3 длиннее остальных (0.9 с).

## 10. Где смотреть

```bash
cd ~/Desktop/game
./run.sh model      # витрина: крутить мышкой, менять позы и свет
./run.sh character  # верстак с анимациями (1/2/3)
./run.sh            # меню → «Модель ГГ»
```

## 11. Экспорт и Blender

Модель уже экспортирована в **`models/dhampir.glb`** (2.31 МБ, 161 мешей).
Это обычный glTF: открывается в Blender, Godot, Windows 3D Viewer,
на gltf-viewer.donmccurdy.com и в любом просмотрщике glTF.

Пересобрать после правок:

```bash
godot --headless --path . res://tools/export_dhampir.tscn
```

Blender **не обязателен**: вся модель процедурная и правится кодом. Blender
нужен, только если захочется лепить скульптуру руками или делать настоящий
скиннинг/риггинг под анимации mocap. Для текущей стилистики (AA-инди)
достаточно того, что есть.

## 13. Что дальше

1. **LOD**: 2–3 уровня, переключение по дистанции.
2. **Смерть/рагдолл**: падение, потеря шляпы.
3. **Trail клинка** на ударах (шейдер уже есть в проекте).
4. **Портрет** для меню и экрана загрузки — рендер из витрины.
5. **Плащ от ветра и дождя**, а не только от скорости.
6. **Меч в руке в бою**: не убирать после каждого удара, если зажат блок.
7. **Конь** для катсцен.
