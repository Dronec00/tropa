# Как развернуть «Тропу» на Windows

## 1. Поставить Godot

Скачай **Godot 4.7** (стандартная сборка, не .NET):
https://godotengine.org/download/windows/

Распакуй, например, в `C:\Godot\Godot_v4.7.2-stable_win64.exe`.
Установка не нужна — это один exe.

## 2. Получить проект

Репозиторий приватный (`github.com/Dronec00/tropa`), поэтому:

**Вариант А — GitHub Desktop:** войти в аккаунт → Clone repository → `Dronec00/tropa` → выбрать папку.

**Вариант Б — git:**
```bat
git clone https://github.com/Dronec00/tropa.git C:\game\tropa
```

**Вариант В — архив:** скачать ZIP с GitHub и распаковать.

## 3. Открыть и запустить

1. Запусти Godot.
2. «Import» → выбери `project.godot` из папки проекта → «Import & Edit».
3. Первый запуск 1–2 минуты: Godot импортирует текстуры и шейдеры.
4. Нажми **F5** — запустится меню.

## 4. Управление

| Клавиша | Действие |
|---|---|
| WASD | идти |
| мышь | камера |
| ЛКМ | удар |
| ПКМ | блок |
| Пробел | перекат |
| Tab | захват цели |
| Q | фляга |
| F | факел |
| E | костёр |
| T | время суток |
| F3 | счётчик FPS |
| Esc | пауза |

## 5. Если тормозит

Меню → **Качество** → «Низкое» (отключает SDFGI, объёмный туман, SSR, тени и режет траву до 55 000).

Дополнительно:
- уменьшить окно или поставить `window/size/viewport_width=1280` в `project.godot`;
- в меню паузы ничего не меняется — качество применяется при входе в мир.

## 6. Собрать exe

1. Editor → Manage Export Templates → Download (~1 ГБ).
2. Project → Export → Add → Windows Desktop.
3. Export Project → выбрать папку.

## Запуск без редактора

В корне лежит `run.bat`: положи рядом `Godot.exe` или поправь путь внутри файла, затем двойной щелчок.

## Что не переносится

- `tools/make_desktop_app.sh` — только для macOS.
- Папка `.godot/` не в git: на Windows она создастся заново при первом открытии.
