# Референсы

Сюда можно кидать картинки: лес, идолы, камни, кора, мхи, свет.

## Зачем

Я не могу по фото автоматически сделать модель — геометрия строится кодом.
Фото помогают выбрать **пропорции, силуэт, цвет и плотность**, а не заменяют ассеты.

## Что реально помогает

1. **Направление словами**: «как на фото, но темнее и уже», «ветви ниже», «ствол толще».
2. **2–3 фото на тему** — этого достаточно, больше не нужно.
3. **Готовые 3D-ассеты** (glTF/OBJ) — вот они меняют качество по-настоящему.

## Лицензии

Картинки из интернета нельзя класть в коммерческий билд. Для референса — можно
держать локально, но не коммитить. Поэтому `references/*` в `.gitignore`,
кроме этого файла.

Безопасные источники бесплатных ассетов: Poly Haven (CC0), ambientCG (CC0),
Kenney (CC0), Sketchfab с фильтром CC.

`slavic sanctuary stones`, `mossy granite`, `birch grove backlight`.
